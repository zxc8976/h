# CRD Lens

**Chrome Remote Desktop にクライアント側のカスタム拡大縮小と画面パンを追加します。リモート PC の解像度を変更する必要はありません。**

[繁體中文](README.md) · [English](README.en.md) · **日本語**

> **ステータス：** 実験的な初期リリース（v0.2.0）

CRD Lens は、Chrome Remote Desktop の手軽さはそのままに、リモート画面の表示サイズをもう少し自由に調整したい人向けの小さな Chrome 拡張機能です。

高解像度のリモート PC では、「等倍だと小さすぎる」「画面に合わせると大きすぎる」という状況が起こることがあります。CRD Lens は既存のリモート接続にローカル側の表示コントロールを追加し、リモート Windows の解像度を変更せずに表示倍率や表示位置を調整します。

## なぜ CRD Lens？

よくある状況：

- リモート PC が高解像度ディスプレイを使用している
- 等倍表示では文字や UI が小さすぎる
- 「画面に合わせる」では大きすぎる
- リモート PC の解像度を変更すると、後で現地で使うときに戻す必要がある

CRD Lens は、この中間のニーズを埋めるためのツールです。

## 機能

- **50%～125%** のカスタム倍率
- 5% 刻みで調整
- **85%** / **100%** のクイックプリセット
- 前回の倍率を保存
- 右下のコントロールパネルを小さく折りたたみ可能
- **Alt + マウスホイール**：ローカル側でリモート画面をパン
- **Alt + Shift + マウスホイール**：横方向にパン
- Alt を押していない通常のホイール操作は、そのままリモート PC に送信
- 表示位置のリセット
- Chrome Remote Desktop の表示領域を再検出
- リモート PC の表示解像度を意図的に変更しない

## インストール

現在は Chrome の「パッケージ化されていない拡張機能」として配布しています。

1. この repository をダウンロードまたは clone します。
2. Chrome で `chrome://extensions` を開きます。
3. **デベロッパー モード**を有効にします。
4. **パッケージ化されていない拡張機能を読み込む**をクリックします。
5. `crd-lens` フォルダを選択します。
6. Chrome Remote Desktop を開く、または再読み込みします。
7. リモート PC に接続します。

右下に **CRD Lens** コントロールが表示されます。

## 操作

| 操作 | 動作 |
|---|---|
| スライダー | 50%～125% の倍率を設定 |
| `-5` / `+5` | 5% ずつ調整 |
| `85%` | 85% に切り替え |
| `100%` | 100% に戻す |
| `–` | コントロールを折りたたむ |
| 折りたたんだピルをクリック | コントロールを展開 |
| `Alt + ホイール` | ローカル側で画面をパン |
| `Alt + Shift + ホイール` | 横方向にパン |
| 通常のホイール | そのままリモート PC に送信 |
| 位置をリセット | ローカルのオフセットを 0 に戻す |
| 再検出 | CRD の表示領域を再検索 |

## 仕組み

CRD Lens が動作するのは次の URL のみです：

`https://remotedesktop.google.com/*`

現在の実装では、拡大縮小に Chromium の CSS `zoom`、表示位置の移動にローカル transform を使用しています。

目的は、**リモート PC の設定を変えるのではなく、手元での「見え方」だけを調整すること**です。

## 権限

CRD Lens が要求する権限：

- `storage`：倍率とパネル状態の保存
- `remotedesktop.google.com`：Chrome Remote Desktop のページ上だけでコントロールを追加

現バージョンには、分析・トラッキング・アカウントアクセス・外部バックエンドはありません。

## 既知の制限

このプロジェクトはまだ実験段階です。

Chrome Remote Desktop は Web アプリのため、内部 DOM が変更される可能性があります。Google 側の更新によっては、CRD Lens の表示領域検出ロジックも更新が必要になる場合があります。

ブラウザのバージョン、ディスプレイ構成、CRD の更新内容によっては：

- 「再検出」が必要になる
- 特殊な倍率でポインター位置の確認が必要になる
- 一部レイアウトではパン範囲の調整が必要になる

表示がおかしい場合は、まず **100%** に戻してください。

## プライバシー

CRD Lens は、リモートデスクトップの内容を意図的に読み取ったり外部へ送信したりしません。

現バージョンには telemetry や外部サーバーはありません。

ただし、パッケージ化されていない拡張機能をインストールする前に、ソースコードを確認することをおすすめします。
