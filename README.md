# CRD Lens

**為 Chrome Remote Desktop 增加用戶端自訂縮放與畫面平移，不需要修改遠端電腦解析度。**

**繁體中文** · [English](README.en.md) · [日本語](README.ja.md)

> **目前狀態：** 實驗性早期版本（v0.2.0）

CRD Lens 是一個小型 Chrome 擴充功能，適合喜歡 Chrome Remote Desktop 的便利性，但希望能更自由控制遠端桌面顯示大小的人。

Chrome Remote Desktop 在高解析度遠端電腦上，常會遇到「原始大小太小、符合視窗又太大」的情況。CRD Lens 在既有連線上增加本地顯示控制，讓你調整縮放比例與畫面位置，而不用修改遠端 Windows 的解析度。

## 為什麼做 CRD Lens？

常見情況：

- 家裡／遠端電腦是高解析度螢幕
- 原始比例下文字與介面太小
- 「符合大小」又放得太大
- 改遠端解析度雖然有效，但回到遠端電腦本機使用時又得改回來

CRD Lens 就是為了填補這個中間需求。

## 功能

- **50%～125%** 自訂縮放
- 每次 5% 微調
- **85%**、**100%** 快速切換
- 自動記住上次倍率
- 右下角控制器可縮成小膠囊
- **Alt + 滾輪**：只在本機平移遠端畫面
- **Alt + Shift + 滾輪**：左右平移
- 不按 Alt 時，滾輪維持原本行為，照常送到遠端電腦
- 一鍵重設畫面位置
- 可重新偵測 Chrome Remote Desktop 顯示區域
- 不會刻意修改遠端電腦的顯示解析度

## 安裝方式

目前 CRD Lens 以 Chrome「未封裝擴充功能」形式提供。

1. 下載或 clone 此 repository。
2. Chrome 開啟 `chrome://extensions`。
3. 開啟右上角 **開發人員模式**。
4. 點選 **載入未封裝項目**。
5. 選擇 `crd-lens` 資料夾。
6. 打開或重新整理 Chrome Remote Desktop。
7. 連線到遠端電腦。

右下角應該會看到 **CRD Lens** 控制器。

## 操作方式

| 操作 | 功能 |
|---|---|
| 縮放滑桿 | 50%～125% 自訂倍率 |
| `-5` / `+5` | 每次調整 5% |
| `85%` | 快速切到 85% |
| `100%` | 回到 100% |
| `–` | 將控制器縮小 |
| 點縮小後的小膠囊 | 重新展開 |
| `Alt + 滾輪` | 本地平移遠端畫面 |
| `Alt + Shift + 滾輪` | 左右平移 |
| 一般滾輪 | 照常傳給遠端電腦 |
| 重設位置 | 將本地畫面偏移歸零 |
| 重新偵測 | 重新尋找 CRD 顯示區域 |

## 運作方式

CRD Lens 只會在以下網址執行：

`https://remotedesktop.google.com/*`

目前使用 Chromium 的 CSS `zoom` 處理縮放，再利用本地 transform 處理畫面平移。

核心概念是：

**只改你這一端「怎麼看」遠端桌面，而不是改遠端電腦本身的顯示設定。**

## 權限

CRD Lens 目前只要求：

- `storage`：記住縮放倍率與控制器狀態
- `remotedesktop.google.com`：只在 Chrome Remote Desktop 頁面加入控制功能

目前版本沒有分析追蹤、沒有帳號存取，也沒有外部後端。

## 已知限制

這仍是一個實驗性專案。

Chrome Remote Desktop 是 Web App，內部 DOM 隨時可能更新。如果 Google 改動頁面結構，CRD Lens 的顯示區域偵測方式可能也需要跟著更新。

不同瀏覽器版本、螢幕配置或 CRD 改版下，可能遇到：

- 需要按一次「重新偵測」
- 特殊倍率下需要再次確認滑鼠座標是否正確
- 部分畫面配置的平移範圍還需要進一步調整

如果畫面出現異常，建議先切回 **100%**。

## 隱私

CRD Lens 不會刻意讀取或傳送遠端桌面的內容。

目前版本沒有 telemetry，也沒有外部伺服器。

即使如此，安裝任何未封裝 Chrome 擴充功能前，仍建議先檢查原始碼。
